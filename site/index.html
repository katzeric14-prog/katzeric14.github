Как это работает

Три шага до игры

Установите лаунчер

Запустите установщик и выберите папку. Ярлыки появятся на рабочем столе и в меню «Пуск».

Выберите сборку

Версия, Fabric или Forge. Лаунчер скачает игру, библиотеки и нужную версию Java автоматически.

Играйте

Добавляйте моды, ресурспаки и шейдеры из каталога в пару кликов и запускайте игру.

Требования

Что нужно для запуска

Никаких ручных библиотек и отдельных установок Java — только Windows и интернет для первой загрузки.

  • Windows 10 или 11. 64-битная система рекомендуется для тяжёлых сборок.
  • .NET Framework 4.x. Уже входит в Windows 10 и 11, отдельно ставить не нужно.
  • 4 ГБ ОЗУ минимум. Для сборок с модами и шейдерами лучше 8–16 ГБ.
  • Интернет. Для скачивания игры, модов, ресурспаков, шейдеров и Java.
  • Без прав администратора. Установка в папку пользователя, обновления применяются автоматически.

Вопросы

Коротко о главном

Лаунчер бесплатный?

Да. Ни подписок, ни рекламы, ни встроенных покупок. Скачайте установщик и пользуйтесь.

Нужен ли аккаунт Microsoft?

Не обязательно. Можно играть под офлайн-ником на офлайн-серверах. Для официальных серверов и скинов нужен Microsoft-аккаунт с Minecraft.

Нужно ли устанавливать Java отдельно?

Нет. Лаунчер сам найдёт подходящую версию Java или скачает её при первом запуске.

Где хранятся игра и настройки?

Игра и сборки — в %APPDATA%\.vexor, настройки лаунчера — в %APPDATA%\VexorLauncher. Удаление программы не затрагивает эти папки.

Поддерживаются ли шейдеры?

Да, через Iris для Fabric и OptiFine. Каталог подбирает версию шейдеров под вашу версию Minecraft.

Почему SmartScreen предупреждает?

Установщик не подписан платным сертификатом. Скачивайте файл только с этой страницы и проверяйте его имя перед запуском.

Как обновляется лаунчер?

При запуске он сам проверяет новую версию, скачивает файлы по HTTPS, сверяет SHA-256 и перезапускается. Вручную искать обновления не нужно — можно только нажать «Обновления» в настройках.

Нужны ли права администратора?

Нет. Лаунчер ставится в папку пользователя, поэтому обновления проходят без запроса UAC. Удалить его можно через «Параметры → Приложения».
